# رفيق الحفظ 📖🎙️

موقع عائلي لتسميع القرآن الكريم بالصوت: تقرأ، والموقع يتابعك كلمة كلمة ويكشف الأخطاء.
مجاني بالكامل: بدون سيرفر، وبدون اشتراكات، وبدون قاعدة بيانات.

## المزايا
- **اختبار حفظ**: الآيات مخفية وتنكشف كلمة كلمة مع قراءتك.
- **قراءة مع متابعة**: النص ظاهر ويتلوّن حسب قراءتك.
- **كشف الأخطاء**: كلمة خطأ 🟥، كلمة سقطت 🟧، كلمة أخطأت فيها ثم صحّحتها 🟨، تلميح 🟦.
- **ملفات للعائلة**: كل شخص له تقدّمه، وأيامه المتتالية، وهدفه اليومي.
- **كلمات للمراجعة**: الكلمات اللي تتكرر أخطاؤك فيها، مع زر لتسميعها مباشرة.
- **الاستماع لقارئ** (العفاسي، الحصري، المنشاوي، وغيرهم) للمراجعة.
- **نسخة احتياطية**: تصدير واستيراد التقدّم لنقله بين الأجهزة.
- يمكن إضافته للشاشة الرئيسية في الجوال كأنه تطبيق.

### 🧪 تدقيق التشكيل (تجريبي) — `tashkeel.html`
صفحة منفصلة تستخدم نموذج ذكاء اصطناعي مدرّب على التلاوة
([tarteel-ai/whisper-base-ar-quran](https://huggingface.co/tarteel-ai/whisper-base-ar-quran)، نسخة ONNX)
يشتغل **داخل الجهاز** ويكتب ما يسمعه بالتشكيل، فيكشف أخطاء الحركات إضافة للكلمات.
- يتحمّل أول مرة (~١٦٠ ميجا) ثم يبقى محفوظاً في المتصفح.
- الحكم يظهر بعد كل وقفة في القراءة.
- على تلاوات صحيحة لثلاثة قرّاء (٤٨٩ كلمة) لم يُسجّل أي خطأ تشكيل وهمي.

## المتصفحات
- آيفون/آيباد: **Safari** (لازم يكون "الإملاء" مفعّل: الإعدادات ← عام ← لوحة المفاتيح).
- أندرويد والكمبيوتر: **Chrome** أو **Edge**.
- Firefox لا يدعم التعرّف على الصوت.

التعرّف على الصوت من المتصفح نفسه (Google في Chrome، وApple في Safari)، لذلك يحتاج إنترنت.

## البنية
| الملف | الوظيفة |
|---|---|
| `js/harakat.js` | مقارنة الحركات بين المصحف وما كتبه النموذج |
| `js/tashkeel.js`, `js/whisper-worker.js`, `js/recorder.js` | صفحة تدقيق التشكيل: النموذج، والتسجيل مع كشف الوقفات |
| `js/matcher.js` | تطبيع النص العثماني ومطابقة ما سُمع بالكلمات المتوقعة |
| `js/speech.js` | التعرّف على الصوت من المتصفح |
| `js/store.js` | الملفات الشخصية والتقدّم (localStorage) |
| `js/app.js` | الواجهة |
| `data/` | نص المصحف (الرسم العثماني) مقسّم حسب السور |
| `scripts/build-data.py` | توليد ملفات `data/` من بيانات Tanzil |
